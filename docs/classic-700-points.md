# Classic Noillirk: seven prompts, one ascent

[Classic Noillirk](https://noillirk.pro/classic) is the complete short game: **7 questions, 15 seconds each, up to 700 points**.

- Aim for the most common answer, not the cleverest one.
- After a result you can start another Classic run right away.
- Repeat Classic runs are practice; the ranked attempt is the [Daily](https://noillirk.pro/daily).
