# Noillirk Classic replays: no daily cap, but questions can recur

Source: [Classic Noillirk](https://noillirk.pro/classic) · Home: [Noillirk.pro free common-answer game](https://noillirk.pro/)

## What Classic is

Seven questions, 15 seconds each, up to 700 points (displayed as 14 km). Pick Classic when you want a complete game in one sitting.

## Replaying

- There is **no daily cap** on Classic sessions. You can start another run right after the result.
- Repeated play does **not** mean an unlimited supply of different questions. Questions can come up again.

## When to choose something else

| You want | Use |
|---|---|
| The same seven questions as everyone today | [Daily](https://noillirk.pro/daily) (changes at 00:00 UTC; first official attempt counts) |
| One long flight | Endless (three balloons) |
| Friends answering the same prompts later | A challenge link from a completed result with no pending answers |
| Everyone online at once | Multiplayer room, up to 30 players |

Answer boards are AI-generated estimates awaiting editorial review.
