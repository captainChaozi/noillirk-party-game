# Noillirk: when to retry an answer after a connection drop

Source: [Noillirk Help](https://noillirk.pro/help) · Game: [Noillirk.pro](https://noillirk.pro/)

## Checking vs pending

- **Checking**: a verdict is in progress.
- **Pending**: a saved answer needs a later verdict.

In both cases, wait. Do not submit a different answer.

## Receipt time is what counts

A server-received answer is judged against its receipt time, not the time the verdict arrives. An answer received before the deadline can finish judging afterwards.

## If the connection drops before a reply

1. Reconnect.
2. Use the check or retry action the game offers. The game checks whether your answer was received.
3. Retry **only** when the game says the answer is still open and time remains.

A network error alone does not prove your answer was lost.

## Daily results

Completed Daily results need all answers resolved before they can rank. Saved pending scores update after judging recovers. For a verdict you disagree with (rather than a delay), see [scoring and feedback](https://noillirk.pro/scoring).
