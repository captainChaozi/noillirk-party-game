# Noillirk spellings and editions

People find this game under many spellings. This page lists them and explains which edition [noillirk.pro](https://noillirk.pro/) is.

## Spellings that refer to the same game

| Spelling | Notes |
|---|---|
| Noillirk | The name used in-game |
| Niollirk | Swapped vowels |
| Noillerk | "e" instead of "i" |
| Noil lirk | Split into two words |
| Noilirik, Noilirrik, Noillirik | Extra or missing letters |
| Noillikirk, Nollirk | Less common typos |

All of these lead to the Classic, Daily, Endless and multiplayer modes at [noillirk.pro](https://noillirk.pro/).

## Which edition is this?

- **Original Noillirk:** created by Daily. noillirk.pro is not affiliated with Daily.
- **noillirk.pro:** an independently developed version with its own character (Sky Sprout), artwork and question boards. See [about](https://noillirk.pro/about).

## What is the same idea

Read a prompt, name something familiar, and score by how high your answer sits on an answer board.

## What is specific to noillirk.pro

| Feature | Detail |
|---|---|
| Boards | AI-generated estimates, not a player survey; awaiting editorial review |
| Classic | 7 questions × 15 s, up to 700 points (14 km), no speed bonus |
| Daily | Same seven prompts per UTC date, one official attempt |
| Endless | Three balloons; a pass or timeout uses one; Sky High restores one |
| Multiplayer | Unlisted private or public rooms, up to 30 players |
| Sky Passport | 52 destinations unlocked by score ([worlds](https://noillirk.pro/worlds)) |
| Account | None needed; guest profile via browser cookie |
