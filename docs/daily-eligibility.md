# Daily 成绩资格说明（Daily eligibility）

> 适用于 [Noillirk.pro](https://noillirk.pro/) 的 Daily 模式。依据站内 [Daily 页](https://noillirk.pro/daily)、[排行榜](https://noillirk.pro/leaderboard) 与 [帮助页](https://noillirk.pro/help) 整理，2026-11-03 核对。

## 一句话

每个 UTC 日期大家拿到同样的 7 道题（00:00 UTC 换题），**只有当天第一次正式开始的那一局算成绩**。

## 规则表

| 情况 | 能否上榜 | 说明 |
|---|---|---|
| 当天第一次正式 Daily，全部完成 | ✅ | 开始时即被保留；中途回来继续不会重置分数 |
| 同一天的练习重玩（practice replay） | ❌ | 练习永远不会替换正式成绩；先完成正式局再练习 |
| 提前结束（ended early） | ❌ | 视为不完整，不进榜 |
| 有答案仍在等待判定（pending） | ⏳ | 成绩为临时状态，判定完成后才能上榜 |
| Classic / Endless | ❌ | 不进 Daily 榜，Classic 不限局数 |

## 排名规则

- 满分 700（7 × 100）。
- 同分依次比：Sky High 个数 → 有效答案数 → 更早完成 → 固定 run ID。
- 答题速度不加分；分数均由服务器计算。

## 找不到成绩时

1. 确认是同一浏览器/设备的保存进度（帮助页有“查找已保存尝试”的说明）。
2. 确认没有 pending 答案。
3. 确认当天第一局没有提前结束。

## 和朋友比

已完成且无 pending 答案的 Classic 或 Daily 结果，可以生成同题挑战链接；该挑战有自己单独的排行榜。
