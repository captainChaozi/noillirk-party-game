# Connection and missing-result help

Summary of the troubleshooting guidance on the [Noillirk help page](https://noillirk.pro/help) for [Noillirk](https://noillirk.pro/).

## My answer may not have gone through

- A server-received answer is judged against its receipt time, not the time the verdict arrives.
- If the connection drops before a reply, the game checks whether the answer was received.
- Reconnect and use the offered check or retry action. Retry only when the game says the answer is still open and time remains.
- A network error alone does not prove your answer was lost. Saved pending scores update after judging recovers.

## A friend cannot join my room

- Check the six-character room code with the host.
- A room can be full, already playing or expired.
- Reopen the lobby after the match or send a new invitation; do not keep retrying an expired code.
- A new game needs at least two players online.

## I disconnected from a room

Return with the same browser profile and room link. The room attempts to reconnect, but the shared clock continues; reconnection cannot restore missed time or guarantee a seat indefinitely.

## My progress or Daily result is missing

Flights are stored on the server and linked to a guest identity. Use the same browser profile, then check the leaderboard eligibility rules.

## I disagree with a verdict

That is a scoring question, not a delay. Open the flight log after question seven and report it; see [scoring](https://noillirk.pro/scoring).
