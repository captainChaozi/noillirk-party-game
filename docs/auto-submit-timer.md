# Noillirk: fifteen-second timer and auto-submit

Site: https://noillirk.pro/

Classic and Daily questions last fifteen seconds. When the clock hits zero the client submits the current field or records a miss—there is no speed bonus. Pending answers and board notes: [scoring](https://noillirk.pro/scoring). Controls: [how to play](https://noillirk.pro/how-to-play).
